# Domain-document routing

Before naming a domain concept, read `CONTEXT.md` in `agentshouse/mdruntime`.
Then use the owner map in `ARTIFACT-AUTHORING.md` to load only the current
requirements, ADRs, PRDs, or built-state description relevant to the work.

Use every term in its glossary sense and avoid synonyms named by its `_Avoid_`
block. If the needed term is absent, do not invent a synonym. Return a real
vocabulary gap to `/domain-modeling` in `agentshouse/mdruntime`. If current
owners conflict, use the conflict rule in `ARTIFACT-AUTHORING.md`.
